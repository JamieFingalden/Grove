## 场景清单（初始全部「未执行」；状态只在实际 GUI＋CLI 判据完成后更新）

### A 分行操作与数据完整性
- A1 同文件同时有已暂存＋未暂存改动，两个相隔 hunk＋同 hunk 增删替换混合：分行暂存；CLI 核对索引 patch 恰为选中内容、未选内容留在工作区
- A2 已分行暂存的部分再取消暂存；索引与工作区字节核对
- A3 丢弃选中行：确认对话框点「取消」→ 文件字节与 git status 完全不变；再实际丢弃 → 只有选中内容消失
- A4 边界数据一种（无末尾换行 / CRLF / 中文＋空格文件名，按造数可行性选）下重复分行关键路径

### B 冲突解决与操作恢复
- B1 合成两分支文本冲突：Grove 冲突界面当前/传入分支标注、逐块采用、保留双方；关键操作前后文件 hash＋git status
- B2 冲突块撤销（撤销已做的采用选择）
- B3 尚有冲突标记时「标记已解决」应被保护（拒绝或警告）
- B4 一侧删除（delete/modify）或二进制冲突（无文本标记）：保留/删除符合选择

### C Rebase 与未提交改动保护
- C1 本地测试分支 GUI 发起 rebase，工作区有未提交改动：autostash 行为与结束后恢复
- C2 冲突后「中止」：原分支指向、提交、未提交内容全部恢复（SHA/索引/内容判据）
- C3 冲突后「继续」或「跳过」至少完成一个实际流程

### D 编辑器与并发修改
- D1 编辑器打开后 CLI 改同一合成文件磁盘内容，再 GUI 保存：是否提示外部修改／拒绝覆盖／静默丢失
- D2 未保存时点完成/取消/重新加载的确认语义；取消后磁盘不变。不重复登记 Issue #11；根因不明的新现象挂关联观察

### E 工作树与输入边界
- E1 分支已被其他工作树占用：创建应明确报错且不产生半成品
- E2 非法分支名（`../bad` 或空白）：报错且不写本轮根外任何路径
- E3 目标目录已存在且有文件：报错并保护原目录内容
- E4 删除对话框取消／保留分支／锁定保护组合观察

### F 标签与推送失败
- F1 重名标签、非法标签名、从历史提交建标签（不误打 HEAD）、取消创建无副作用
- F2 删除本地标签后本地 bare 远端标签保留（若产品有该入口）
- F3 remote 指向本轮不存在路径：错误提示、按钮恢复、上游不被改写（不访问公网）

### G 多仓库/页面状态串扰
- G1 两个专用仓库同名 README.md 不同内容/暂存状态：快速切换仓库与工作树、历史/变更页，diff、计数、草稿、按钮不串项目
- G2 外部修改合成文件后刷新、重选文件、切页面再回：缓存正确性；与 Issue #11（保存刷新）区分

### H 遗漏项与体验边界
- H1 正常退出并重开安装副本：测试仓库/页面恢复（第 1 轮未执行）
- H2 历史「提交人＋路径＋字面量」组合搜索、清空后数量恢复；长提交正文/窄窗口至少观察一个实际布局问题
- H3 Daily/Workspace 若无法限定为测试项目，记录隔离限制；不读/改用户真实项目数据
